# هيئة الرقابة — اللوائح والأنظمة

موقع ثابت بسيط ومتجاوب ومناسب للنشر على GitHub Pages.

## التشغيل
افتح `index.html` مباشرة أو ارفع الملفات إلى مستودع GitHub.

## GitHub Pages
1. أنشئ Repository جديد.
2. ارفع `index.html` و `style.css` و `script.js`.
3. من Settings ثم Pages اختر Branch: `main` والمجلد `/root`.
4. احفظ وانتظر إنشاء الرابط.

## التعديل
القوانين موجودة في `script.js` داخل مصفوفتَي `rpLaws` و `oversightLaws`.
يمكنك تعديل العناوين والنصوص وإضافة قوانين جديدة بنفس الصيغة.
