# هيئة الرقابة — اللوائح والأنظمة

الموقع يحتوي على قوانين الرول بلاي والرقابة العامة وقوانين سيرفر الديسكورد.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /root → Save

## Discord Webhook
لا تضع رابط الـWebhook داخل الكود. من GitHub افتح:
Settings → Secrets and variables → Actions → New repository secret

اسم السر: `DISCORD_WEBHOOK_URL`

ضع رابط الـWebhook في قيمة السر فقط. عند كل Push إلى `main` سيتم إرسال رسالة إلى Discord وتنتهي بـ:

By : Head of Supervision
